# SWANIX — Personal AI Agent

A 3D, Gemini-powered personal AI agent by Gurupriya Arindam.

- Live: https://arindam5294.github.io/swanix-ai/
- Open it, tap the gear icon, and paste a free Gemini API key from https://aistudio.google.com/apikey. The key stays in the tab's memory only.
- Edit `index.html` to change the look, the system prompt (search for `You are SWANIX`) or the default model.
